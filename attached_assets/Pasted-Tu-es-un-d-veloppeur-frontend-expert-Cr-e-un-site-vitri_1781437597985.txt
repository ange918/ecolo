✅ RÈGLES IMPORTANTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Aucune image externe — utilise uniquement des SVG inline ou des divs colorées comme placeholders pour les photos
2. Tout le texte est en FRANÇAIS
3. Aucune librairie UI externe sauf celles listées (pas Shadcn, pas MUI)
4. Le site doit être 100% responsive (mobile first)
5. Toutes les animations Framer Motion utilisent whileInView avec viewport={{ once: true }} pour ne se déclencher qu'une fois
6. Le bouton "Contactez-nous" dans la Navbar scrolle vers la section #contact
7. Les couleurs viennent UNIQUEMENT du design system défini — pas de gris standard Tailwind
8. Chaque section a son propre fichier composant isolé
9. Aucun console.error ne doit apparaître au lancement

Lance l'application avec : npm run dev
